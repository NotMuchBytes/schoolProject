# Arabic font

`NotoSansArabic-Regular.ttf` is the project-wide GUI font. It is distributed
under the SIL Open Font License 1.1; see `OFL.txt` in this directory.

Source: https://github.com/notofonts/notofonts.github.io/tree/main/fonts/NotoSansArabic/hinted/ttf

`NotoSans-LatinGreek.ttf` supplies complete English, Latin, and Greek glyphs as
the fallback font. It is the Noto Sans variable font from Google Fonts and is
also distributed under the SIL Open Font License 1.1.

Source: https://github.com/google/fonts/tree/main/ofl/notosans
